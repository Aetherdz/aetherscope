Scope that keeps receipts.

Know exactly what you are authorized to test. Aetherscope reads a scope file and answers one question about every target: in-scope, out-of-scope, or unknown.

Get started Read the docs
aetherscope 
$

Install

pip install aetherscope

Features

Scope parsing

Exact hosts, wildcard domains, negations, host:port, URL rules with scheme and path, IPs, and CIDR ranges. Comments and blank lines ignored.

Negation wins

An out-of-scope rule overrides any inclusion. If a target is explicitly denied, it is denied — no ambiguity.

Pipe friendly

Feed a subdomain list on stdin, keep only in-scope entries on stdout. Composable with anything.

Exit codes

0 in-scope, 1 out-of-scope, 2 unknown, 3 error. Script-friendly gatekeeping.

Reports

JSON and Markdown reports with a per-target verdict and the matched rule. Your testing record, versioned.

Zero deps

Pure standard library, Python 3.8+. Install anywhere, run anywhere.

Usage

# classify targets
aetherscope -s scope.txt check api.example.com admin.example.com

# keep only in-scope targets from a list
cat recon_subs.txt | aetherscope -s scope.txt filter > in_scope.txt

# show parsed rules
aetherscope -s scope.txt parse

# build a markdown report
aetherscope -s scope.txt report --format markdown -o report.md
